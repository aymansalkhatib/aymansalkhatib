## The invisible part

The work users never notice, and would notice at once if it were missing.

- **Security** — authentication and authorization with Spring Security, JWT and OAuth2, plus rate limiting, temporary lockouts and alerts on suspicious sign-ins.
- **Consistency** — locking that stops race conditions and two people overwriting each other's changes.
- **Performance** — lean data access with JPA and Hibernate, and caching with Redis.
- **Traceability** — audit trails and structured logs that explain what happened, and why.
- **Capacity** — load tests with k6 and JMeter before real traffic arrives.
- **Delivery** — Docker, Kubernetes and CI/CD pipelines with rolling updates and autoscaling.
